# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Fashion shoppers browse tenant-specific stores and purchase garments. Store owners and staff manage products, inventory, orders, sales and reports.

## Product Purpose

AURA combines a fashion storefront with multi-store SaaS operations and virtual try-on.

## Capabilities and Constraints

The existing application uses React 18 and Vite. Preserve routing, tenant isolation, authentication, cart state, payment behavior, existing APIs and actual analytics data. This task changes web presentation only. UI language remains Spanish.

## Brand Commitments

The user supplied champagne silk, charcoal/cream, glass surfaces, oversized editorial serif lettering, natural scroll motion, and interactive garment imagery as explicit visual references.

## Evidence on Hand

Existing product images are served from API uploads. Existing screenshots are in the repository's untracked `.playwright-mcp/` directory. The user supplied three target references and a detailed design brief. A single product image is not evidence of a complete 360-degree capture or measurable garment fit.

## Product Principles

- Preserve real commerce and administration workflows.
- Motion should support garment exploration without obscuring controls.
- Retain accurate product and analytics data.
- Make core content available without WebGL and with reduced motion.
